# MayCAD Mac

**在 AutoCAD for Mac 中用短命令画门窗、衣柜、柜体、窗帘和灯带，并完成居中、等间隙排列与批量打印。**

19 个绘图／编辑命令，使用原生 AutoLISP 和 DCL。手动使用不需要 AI、MCP、Windows ActiveX 或额外的商业绘图插件。

当前为 `0.1.0-preview`。已在 AutoCAD 2026 for Mac 的独立空白图进行加载和几何检查；尚未在第二台 Mac 或其他 CAD 版本验证。公开版使用通用图层和程序化基础符号，个人标准、客户图纸及精细参考图块均不在此仓库中。

## 安装：下载、解压、运行

1. 在本页点 **Code → Download ZIP**，解压。
2. 先读下文安装行为，再双击文件夹里的 **install.command**。如系统提示没有执行权限，可打开终端，输入 `bash `，把该文件拖进去，再按回车。
3. 重启 AutoCAD，打开一个空白图，输入 **MAYINFO**。显示版本和命令列表即加载成功。

安装到当前用户的应用支持目录，尝试接入 AutoCAD 2026 各语言配置的 `acaddoc.lsp`。会备份旧插件与已有启动文件，追加有标记的加载片段；不会覆盖 PGP、图纸、字体或打印样式。启动片段仅将安装目录加入受信任路径，不关闭安全加载。

如果已有其他工具的 `acaddoc.lsp` 搜索优先级更高，自动加载可能被遮挡：在 AutoCAD 中输入 **APPLOAD**，选择已安装的 `maycad.lsp` 加载。本版不接管其他插件的启动文件；不同工具重名时需要自行协调。

PDF 打印不需要编译器。JPG 功能需要 macOS Swift 编译器；安装时若已有 Xcode Command Line Tools，会本机构建转换程序。未安装编译器或构建失败时仍可使用 PDF，不会自动下载开发工具。安装器不需要管理员权限。

## 命令速查

切到英文输入法，输入命令后按空格／回车；大小写均可。

| 命令 | 功能 | 用法 |
| --- | --- | --- |
| SS | 水平构造线 | 连续点取经过点，Esc 结束 |
| XX | 垂直构造线 | 连续点取经过点，Esc 结束 |
| TT | 隐藏／恢复对象 | 选对象确认隐藏；空选确认恢复对象隐藏／隔离 |
| TY | 对象独显／恢复 | 选对象确认独显；空选确认恢复 |
| D | 图层隔离 | 选对象确认；模型空间保留本轮首次隔离前状态 |
| DD | 恢复图层 | 恢复本轮第一次 D 之前的开关、冻结、锁定及当前图层 |
| F | 置于最前 | 预选或执行后选对象 |
| B | 置于最后 | 可用于把填充放到下层 |
| ZZZ | 框内居中 | 选对象确认，再选闭合矩形多段线框；支持旋转矩形 |
| FF | 净空隙等宽排列 | 选物体确认，再点排列范围的两个外侧端点 |
| YGG | 一字／L／U 衣柜 | 点角点、拉出范围、点确认；I/L/U 模式，F 换向，S 柜深，R 旋转 |
| YGL | L 型衣柜 | 直接进入 L 型，其余同 YGG |
| YGU | U 型衣柜 | 直接进入 U 型，其余同 YGG |
| GZZ | 高柜／半高柜 | 先设深度和柜型／图层，再点背边两端；S 设置、F 反向 |
| CLPM | 单／双层窗帘 | 先设置，再点基线两端；S 设置、F 反向 |
| EDD | 点划线／LED 字样灯带 | 先选线型和偏移，再点基线两端；与窗帘独立 |
| MM | 七类门型 | 先选门型、单／双开和角度，再点取洞口并用鼠标确认方向 |
| CH | 三点画窗 | 墙面起点、对侧墙面量厚、沿墙终点定宽 |
| QP | 选择图框批量打印 | 框选本批图框确认，设置纸张、CTB、比例及输出格式 |

另外提供 **MAYINFO** 查看版本、**MAYCONFIG** 设置图层映射。

F、B、D、SS 等名称会与已有快捷命令冲突，需要原生命令时输入完整名称，例如 `FILLET`、`BLOCK`、`DIMSTYLE`。命令执行中的 F／B 选项含义以提示为准。

## 自己选图层

缺失图层在首次需要时按通用的 `MayCAD-*` 名称新建，颜色和线宽使用基础设置；已有图层定义不会被覆盖，关闭／冻结／锁定的目标层会阻止绘制。

输入 **MAYCONFIG**，先输入角色名，再输入自己的目标图层名。映射保存到当前用户的独立设置目录；更新插件不覆盖它，已有对象也不会因此被改层。

| 角色 | 用途 |
| --- | --- |
| wardrobe | 衣柜 |
| cabinet-high / cabinet-low | 高柜／半高柜 |
| curtain / led | 窗帘／灯带 |
| door / door-frame / opening | 门扇／门套／洞口墙面线 |
| window | 窗 |

GZZ、CLPM 的窗口也可选择当前图纸中的图层。需要自己的整套标准时，另外导入私人配置；本仓库不附作者的标准文件或个人图层库。

## 门窗与打印说明

MM 提供内齐平、外齐平、隐形、对开推拉、三扇联动、内齐平2、外齐平2；两种 2 号款采用直边门套。带套门先点内侧墙面、再点对侧外墙面、第三点定宽；鼠标独立选择铰链和内开／外开。隐形、推拉和联动用两点定宽。整樘为块，门宽变化不靠整块非等比缩放。公开版的符号是布局示意，不作为真实产品或施工节点尺寸依据。

CH 生成一个窗块：居中 50mm 玻璃表达，两端各退 50mm 端线，外轨随层、内部细节有独立颜色。CH 和 MM 不自动删除现有墙线或墙体填充。

QP 只收集本次选择中的有效矩形外框，不扫描整图同层图框；内含的较小矩形会被过滤。支持模型毫米、世界坐标系俯视图、CTB、轴对齐四顶点闭合轻量多段线。纸张支持 A4–A1；比例填 `50` 表示 1:50，填 `0` 表示布满。固定比例放不下会停止，不静默缩小。

QP 从本机已有 CTB 中选择，默认 acad.ctb；不会安装个人 CTB。输出到当前用户桌面的新批次目录，可改位置。PDF 原生打印，JPG 从单页 PDF 按 300dpi 转换并保留 PDF。保留“不打印图层”设置，不覆盖同名文件、不保存页面设置。设备依赖 AutoCAD 自带的 High Quality Print PDF 配置；缺失时提示检查配置。

## 更新与卸载

- 更新：下载新版，运行新版 install.command；上一版移动为备份，个人图层映射单独保留。
- 卸载：运行 uninstall.command。只删除未被手改的本插件启动片段；若发现启动片段被修改则保留并提示。程序移到可恢复备份，个人配置和图纸保留。重启 AutoCAD 后生效。
- 受信任目录设置不会在卸载时整表回滚，避免覆盖期间新增的其他工具设置；如不再需要，可在 CAD 设置中删除对应的 MayCAD 安装目录。

## AI 协作（可选）

`SKILL.md` 提供通用操作和验收规则，可另行安装给支持 Skill 的客户端。它不包含个人作图记录，也不会自行安装 AutoCAD 连接。

开发时使用的 [autocad-mcp](https://github.com/adamshels1/autocad-mcp) 是第三方连接项目；若想用 AI 读写 AutoCAD，需单独按其文档配置，Mac 还需相关系统权限及解锁屏幕。手动使用本仓库命令不需要它。完整来源说明见 [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md)。

## 已知边界与验证

只验证了本机 AutoCAD 2026 for Mac。多数生成器用于同一水平面，倾斜 UCS、三维对象及代理对象不在支持范围内。FF 每个图元／块算一件，多线家具先成块；不支持的边界类型会在移动前拒绝。DD 快照只在当前图纸会话存在，关图后不保留。

公开版使用基础符号，效果与私人模板可能不同。验证范围和未完成项见 [VALIDATION.md](VALIDATION.md)。项目适合住宅平面布局，不扩展为自动深化、结构设计或完整施工图软件。
